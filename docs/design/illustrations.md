# SportnNote illustrations: list and prompts

Founder, 2026-10-29: better illustrations and styles. Make the images; Claude then fits them into the UI.

## How to make them
1. **Start every prompt with the style block below**, so all images look like one set.
2. **Format:** PNG with a transparent background (or SVG if your tool can export it). Don't put text, numbers or logos in the picture; the app adds its own words.
3. **Sizes:**
   - **Square spots** (empty states, small moments): 1:1, 800×800 or larger.
   - **Heroes** (top of a screen): 4:3, 1600×1200.
   - **Website cards:** 16:10, 1600×1000.
4. **Name each file exactly as listed** (e.g. `empty-matches.png`), so each one drops straight into place.

### Style block (paste first, every time)
> Flat editorial vector illustration, clean and professional, for a sports scoring app used by schools, colleges and clubs in India. Limited palette: pitch green #0D5A3F, deep green #0A3A2B, lime #C6EE3E as the only bright accent, warm cream #F3F0E8, sand #E9E5DA, ink #14181D. Simple geometric shapes, confident clean lines, soft flat shadows, no gradients. Realistic adult proportions: no big heads, no cartoon faces, no mascots, nothing childish. Diverse Indian athletes, coaches and parents in modern plain sportswear with no numbers or writing. No text, letters, numbers, logos or emoji anywhere. Centred subject, generous empty space, transparent background.
