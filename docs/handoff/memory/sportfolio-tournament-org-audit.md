Audit (2026-08-24) of whether the app can organize any realistic tournament format across all 10 sports. Three code-audit agents mapped creation/config, the fixtures/bracket engine, and scheduling/venues. Report artifact: "Tournament Organization Report" (https://claude.ai/code/artifact/a920fabd-398b-4bdd-87b2-c57971df3b78). Verdict: **strong core, real gaps — most formats, not yet all.**

**Works ✅:** multi-sport tournaments; single & double round-robin; groups (count configurable, uneven ok, positional `i%g` draw); top-N + **best-3rd-placed** advancement (FIFA WC 2026 litmus-proven); seeded single-elim knockout with group de-clash + play-in byes; Super Four/Six; 3rd-place playoff (`thirdPlacePair` in bracket.ts); multi-stage chaining; dynamic knockout (next round created from results); participants (pick/add/self-register, invited/pending/confirmed lifecycle); divisions (age×gender/custom, rostering boundary).

**CRITICAL gaps (block real formats):**
1. **Scheduling/match-management = weakest area.** NO `updateMatch` for date/time/venue (matches write-once → no reschedule); no postpone/cancel status; **venue is free-text only** (`Venue` type + `venue_id` are DEAD code — `createMatch` never writes them); NO conflict detection (venue/time clash, back-to-back, double-booking); no availability/rest rules; no TBD-vs-TBD pre-dated bracket. Affects every tournament.
2. **Team-tie competitions** (a tie = several sub-matches, aggregated) — Davis/BJK Cup, Thomas/Uber/Sudirman, team squash/padel, MLP. Hits 5 sports; no model.
3. **Best-of-X series & two-legged (home&away) knockout ties** — a bracket match is always ONE game. No cricket bilateral series, NBA/EuroLeague playoff series, UCL/Libertadores two-legged KO.

**IMPORTANT gaps:** double elimination + IPL double-chance playoff (Q1/Elim/Q2); tie-breakers (no NRR, no head-to-head; **win=2pts not 3**, not configurable); manual bracket seeding / seeded-pot group draw; group count/size + qualifier counts live only in the ad-hoc GenerateFixtures tool (tournament `structure` = 3 values league/knockout/league_knockout, can diverge from actual fixtures); registration controls (no deadline, min/max, eligibility enforcement — divisions cosmetic; no "withdrawn" status).

**POLISH:** Swiss phase (new UCL); box leagues/promotion-relegation; rotating-partner (Americano); handicap draws; partial pools (VNL); tournament-level venue/rules fields; logo at creation; large-draw labels past R32; medal table for multi-sport.

**Recommended build order:** (1) match edit/reschedule + postpone status; (2) venue entity + conflict detection (wire the dead `Venue` type through `createMatch`); (3) a **series/tie wrapper** (a tie owns N child matches, resolves by aggregate/most-wins) — one primitive unlocks best-of-X + two-legged + team ties; (4) pluggable per-sport tie-breakers + 2-vs-3-pts; (5) structure config on the tournament; (6) double-elim + registration controls. See [[sportfolio-tournament-vision]], [[sportfolio-team-entry-overhaul]], [[sportfolio-devlog]].
