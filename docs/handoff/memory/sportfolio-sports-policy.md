**Only include sports played at an international level.** The test: an international federation plus world championships, or inclusion in multi-sport games (Olympics / Asian Games / Commonwealth Games). Regional-only sports are out.

Throwball was added and then removed the same day for failing this test. Carrom (ICF World Championships), kabaddi (Asian Games), kho-kho (2025 World Cup), pickleball and padel (world championships) pass.

**Why:** the user wants the sport catalogue to be credible internationally.

**How to apply:** check every proposed sport against the test before building, and say which criterion it meets. See [[sportfolio-master-roadmap]].

**Update 2026-10-12:** for international markets the founder added rugby (union + sevens), baseball/softball, ice hockey, netball and American football (NFL) to the roadmap — the earlier "skip NFL/rugby for now" is reversed. See [[sportfolio-international]].
