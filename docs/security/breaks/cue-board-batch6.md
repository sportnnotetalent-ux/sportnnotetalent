# Cue & board batch 6: break it (2026-11-03)

**Source:** expert audit `docs/sport-expert/cue-board.md`, the P2 rows left by batch 5 (14 snooker break make-up, 15 billiards red-to-centre hint, 16 chess in-game arbiter events, 17 chess uneven scores and a second time-control period / delay, 18 carrom board and game awards, 19 pool shot-clock extension and snooker long pot / rest), plus what `cue-board-batch5.md` left "Not done": billiards foul kinds in careers, and the pool rows for ball in hand, push-out choices, re-racks and not-called pots.

**Founder chain:** Info (`src/sports/matchRules.ts`) → Scoring → Stats + Commentary.

**Hard rules:** old match logs replay identically; new payload keys and actions are additive; hostile values are ignored; one scorer on one phone, every new tap optional.

**Process:** quality mandate step 4. Listed after reading the code and **before** any fix. Each fix then got its own failing test first (`tests/cue-board-batch6.test.mts`), then the simulation (`tests/sim-cue-board-batch6.test.mts`).
