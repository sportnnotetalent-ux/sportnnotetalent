# Court and team sports, batch 1: break it (2026-11-02)

**Source:** expert audit `docs/sport-expert/court-team.md`, fixes 1, 2 and 3.

1. **Kabaddi:** the Raider chips go above the one-tap buttons. After a quick "Raider out", an optional "Tackled by?" row names the tackler. It saves as an in-place edit of that raid, through the existing raid edit path.
2. **Volleyball:** the "Block out" fault chip becomes "Block fault (net / over / blocked a serve)", with a hint that a ball off the block and out is the attacker's ⚡ Attack point. The stored key stays `blockout`.
3. **Kabaddi:** "Raider out — no tackle" with a reason: stepped out, baulk line, raid time (30 s) or cant. New optional payload key `rout` on the raid; with no `rout`, a raid replays as the line-out it is today.

**Process:** quality mandate step 4. These points were listed before any code changed, each with Status: Open. Each one then got a failing test first (`tests/court-team-batch1.test.mts`: 17 of 22 failed before the fix) and a seeded simulation (`tests/sim-court-team-batch1.test.mts`: 2,400 kabaddi raids over 60 matches, 600 volleyball rallies).
