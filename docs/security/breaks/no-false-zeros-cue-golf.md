# No false zeros in snooker, carrom and golf — break it first

2026-11-08, wave 1 of `docs/sport-expert/defaults-on/PLAN.md`. Before more "Stats to track" options are switched on by default (wave 3), a stat that the scorer never recorded must not show as 0 or write 0 to careers. The rule is the one racket sports already follow (`docs/security/breaks/describe-done.md` DD11): **tracked means captured**. A stat counts as tracked only once at least one event of that kind was captured in the match (snooker, carrom) or on the card (golf). Switched on with nothing captured means nothing shown and nothing written to careers. Where something was captured, the figures are exactly what they were before, and old saved matches and rounds still replay. Findings come from `docs/sport-expert/defaults-on/cue-board.md` (S1, C1, C2) and `docs/sport-expert/defaults-on/measured.md` (R3 and the penalties note).

Tested. |
| NZG2 | Snooker: a match that tagged long pots but never the rest still writes `restShots 0`. | False zero | Same per-kind rule (NZG1): long and rest are separate kinds. Tested. |

The pure `boardDetail` (engine) builds it, and the screen calls it. Before the first tap, nothing is saved. Tested. |

| NZG9 | Golf: `penalties: 0` is written on every golf line, tracked or not (`golf/engine.ts` `roundStats`). Careers then average "0 penalty strokes" over rounds where nobody was counting. | False zero | **Option chosen: write `penalties` only when at least one penalty stroke was entered on the card.** The stepper exists only when Penalties is tracked, so this equals "tracked AND at least one entered". That is the same trade racket sports made (DD11). Tested. |
| NZG10 | The fix could change figures where something WAS captured, or break replay of old matches and rounds. | Replay | Each fix only removes keys / rows for a kind with zero captures. A 600-user simulation (random matches and rounds, toggles on, random capture) checks that no stat key appears for a kind with zero captures, and that captured figures equal the old calculation. Older tests that pinned the old zeros are updated on purpose with a `// no-false-zeros NZGx` comment. Tested. |
