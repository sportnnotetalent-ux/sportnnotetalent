# Stats to track on by default for new invasion matches: break it (2026-11-08)

Wave 3 of docs/sport-expert/defaults-on/PLAN.md for football, hockey, ice hockey, rugby union and rugby league. The specialist's ON list (docs/sport-expert/defaults-on/invasion.md) becomes the new-match default, with the founder's final calls: football Quick friendlies get the deeper stats too; "Goals / Tries ruled out" stays OFF in every code; possession (football friendlies, hockey, union), six-tackle sets, football passes, hockey video referrals and ice hockey +/- stay OFF. Football key passes go ON once their step is a non-blocking card; ice hockey faceoff zones go ON only if the zone tap no longer blocks. Each sport now has one defaults constant in its `meta.ts` that the format fields, the live settings and their `defaults` all read. Wave 1 (tracked = captured, no-false-zeros-invasion.md) and wave 2 (non-blocking describe cards, describe-invasion.md) come first. Points listed before the fix; each gets a failing test first in tests/defaults-on-invasion.test.mts and a 600-match simulation in tests/sim-defaults-on-invasion.test.mts.

| # | Break | Kind | Fix |
|---|---|---|---|
| DOI1 | **An old match changes.** A saved match has no `track*` key (or a stored `false`). If any reader fell back to the new field default, its buttons, stat lines and Info would gain the new stats on replay. | Data | Only the format-field `default` and the live `defaults` move. Every engine reads stored keys with an OFF fallback (`bool(config.x, false)`, football `readDeepTrack === true`); football's `BASE_TRACKABLE` full-set fallback is untouched. Tested; 600 simulated old-format matches replay deep-equal to the pre-change engine. |
| DOI2 | **Reset turns the new options off.** If a live `defaults` still says `false`, Reset to standard switches the new stats off on a new match. | Wrong setting | Each live `defaults` spreads the sport's one constant. Tested: for every stats toggle, live `defaults` = format default = live field default. |
| DOI3 | **Info shows ON while the engine has OFF.** If Info read the field default for a missing key, an old match would list the new stats as captured. | Wrong Info | `matchCaptures` reads `ls.read(state)`, which is the engine's own state (explicit `false` when absent). Tested on an old match and a new one. |
| DOI4 | **A preset overrides.** A format preset (`set: {...}`) that stamps a `track*` key would undo the new default whenever the preset is picked. | Wrong setting | No preset in the five sports sets a stats key. Tested: every preset's `set` is free of stats keys, so picking one keeps the defaults. |
| DOI5 | **A tournament format saved before.** A tournament created before this change stored its own `track*` values, so its new fixtures stay as saved. | Expected | Holds by design (PLAN, founder decision 3: "Use the new defaults" is a separate button that applies every `group: 'Stats to track'` key). Every stats toggle in the five sports now carries that group (football's "Stats captured" / "Deeper stats (optional)", ice hockey `plusMinus` "Stats" / none, union `trackDetail` none were fixed). Football's `tournamentDefault` (the full set, possession on) is unchanged. Tested. |
| DOI6 | **"N changed" on a brand-new match.** If the live `defaults` and the new-match stamp disagree, a fresh match shows stats options as changed. | Wrong count | `customCount` over the stats toggles is 0 on a new match in all five sports. Football: the standard is the new friendly's set (possession off), so a tournament fixture's possession counts as one change and Reset would turn it off there. Accepted and noted (football's state cannot tell a tournament fixture from a friendly; possession needs a tap at every change, the specialist's R4). Tested. |
| DOI7 | **Voice.** With more tallies on, a spoken goal could be read as a tally ("goal, block by Rao"), or a tally word could start answering by default. | Wrong score | Ice hockey voice checks `goal` before any tally; union and league voice take tries first. Ice hockey faceoff zones still replace the controls with a zone panel on every faceoff (describe-invasion DI16), so they stay OFF. Tested (source checks) and simulated. |
| DOI10 | **A stat the founder kept OFF turns on.** "Goals / Tries ruled out", possession, six-tackle sets, passes, video referrals, +/- and faceoff zones. | Wrong setting | Pinned OFF in the constant, the fields and the live `defaults`. Tested. |

**Status (2026-11-08): fixed / holds.** tests/defaults-on-invasion.test.mts went from 33 failing of 51 to 51 passing. tests/sim-defaults-on-invasion.test.mts covers 600 simulated users (120 per sport) on new matches with random presets, friendly or tournament, and random play. It checks for no false zeros, that every goal / try lands on one action, and that old formats (keys absent, or stored off) replay deep-equal and gain no flag. Pinned tests updated on purpose (`// defaults-on DOIx`): defaults-invasion, football-quick-default, sim-football-quick, football, football-deep, invasion-goal-round2, invasion-batch6 and ice-hockey-deep. tsc clean.
