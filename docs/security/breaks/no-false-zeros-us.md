# No false zeros in US sports: tracked means captured — break it first

2026-11-08, wave 1 of `docs/sport-expert/defaults-on/PLAN.md` (specialist report `docs/sport-expert/defaults-on/us-sports.md`, US-DON-1 gating part, US-DON-4 "gate deep keys on events (R2)"). The founder is about to switch more "Stats to track" toggles on by default (wave 3), so a stat must not show 0 for everyone just because its toggle is on. The rule is the racket one (`docs/security/breaks/describe-done.md` DD11, `src/sports/pointDetail.ts`): a stat counts as tracked only once at least one event of that kind was captured in the match. Switched on with nothing captured shows nothing in the panel or box score and writes nothing to careers. Where something was captured, the figures are unchanged (everyone else on the line still reads a true 0). Old saved matches replay: the stamps they carry (`fbt`, `fdt`, `tgt`, `pdef`) stay as they are; only the "is this stat shown" decision changes, and it is derived from the log.
