# Invasion batch 5: break it (2026-11-03)

**Source:** the expert audit `docs/sport-expert/invasion.md`, the P1 items of size S / M not done in Batch 1 (fixes 1–3), Batch 2 (fix 4, Info) or Batch 3 (fixes 7–8, defaults): fix 5 (football stoppage reason), fix 6 (football penalty conceded), fix 9 (union / league penalty try card), fix 10 (league penalty to the attacking side), fix 11 (hockey card warnings and team-official cards). Plus the Batch 1 side note (B4): the leader rail's "N of M games" note reads crosses, dribbles, offsides, handballs and penalties won / missed as untracked.

**Process:** quality mandate step 4. Listed after reading the code and **before** any fix. Each point then got a failing test first (`tests/invasion-batch5.test.mts`) and a 500+ match simulation (`tests/sim-invasion-batch5.test.mts`).

**Status:** Fixed / Holds (2026-11-03). Not checked in the running app.

## Results
Simulation `tests/sim-invasion-batch5.test.mts`: 600 football matches (over 10,000 taps: stoppages with valid and hostile reasons and refs, penalties with and without the conceded step, fouls on / off), 300 old-style football logs, 600 hockey matches (official cards with hostile names), 600 league matches with six-tackle sets (500+ penalties to the side with the ball, hostile endings, errors on / off), 500 union matches (penalty try + card). statTotals contract on every 20th football / hockey / league match.

Pinned tests updated (they pinned replaced behaviour): `tests/defaults-invasion.test.mts` D6 (trackedKeys moved to `footballTrackedKeys` in actions.ts, so `t.shots` / `t.saves` appear once in index.tsx); `tests/football-pickup-no-players.test.mts` (the penalty's "no players → outcome" path now comes from `penaltyStepAfter`).

Not done here: a "penalties conceded" career stat for football (the foul carries the `pen` flag, so it can be derived later); a voice command for the stoppage reason or "penalty to".
