## Follow-on breaks to check while fixing
- **F1** A precision override equal to the meet's rule is dropped (the event follows the meet again).
- **F2** The event's capture shows on the header line (penalties / lights / jury / team arrows).
- **F3** A match penalty changes who won the end, so set points follow; the record of arrows stays as shot.
- **F4** Maximum score: a player with a pickup is ranked (not NR), and the profile's adjusted gross is unchanged.
- **F5** A start-conduct red card is a DQ with TR 16.5 and counts as `dq` (not `fs`).
- **F6** One official, one phone: every new control is one tap (or one ⋯ then one tap) on the row already being entered.
