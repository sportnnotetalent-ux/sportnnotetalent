# Cricket, cue and board sports: "Stats to track" on by default (new matches): break it (2026-11-08)

Wave 3 of docs/sport-expert/defaults-on/PLAN.md for cricket, snooker, pool, carrom and chess (billiards has no stats switch). Specialist reports: docs/sport-expert/defaults-on/cricket.md and cue-board.md. Built on wave 1 (tracked = captured, no-false-zeros-cue-golf.md: snooker S1, carrom C1 / C2) and wave 2 (one per-ball Done card in cricket, describe-cricket.md).

**Status: Fixed / Holds** (2026-11-08). Listed after reading the code and **before** any change (quality mandate step 4). Each fix got a failing test first (tests/defaults-on-cricket-cue.test.mts), then the simulation (tests/sim-defaults-on-cricket-cue.test.mts).

## What changes (new matches only)

| sport | key | old | new |
|---|---|---|---|
| Cricket | `wagonWheel`, `pitchMap`, `bowlerType`, `extraWhy` | off | **on** |
| Cricket | `ballSpeed` (typed, speed gun), `shotCtrl` (untagged = in control, a false 100%) | off | off |
| Snooker | `trackLongRest` | off | **on** |
| Pool | `trackShotClock` | off | off |
| Carrom | `trackFouls` | off | **on** (`trackBreak`, `trackQueenMiss` stay on) |
| Chess | `trackMoves`, `trackClock` | off | off |

## Breaks

| # | Break | Status |
|---|---|---|
| DOK1 | **An old match changes.** A match created before the flip has the key stored `false`, or no key at all (created before the key existed). If any reader falls back to the new default, the old match starts tracking (cricket detail cards appear, snooker chips appear, carrom fouls row appears) and its replay changes. | **Holds:** only the field `default`s and the live-settings `defaults` change. Every engine reads a missing key as off: cricket `rulesFromConfig` `bool(c[k], false)` and `STANDARD_RULES.wagonWheel` (untouched), snooker `read('trackLongRest') === true`, pool `c.trackShotClock === true`, carrom / chess `readTrack`. Tested: an old config (no keys) replays deep-equal to the same log with the keys stored off; 600-user sim. |
| DOK2 | **Two (or three) sources per sport drift.** Cricket's field defaults and `LOCAL_RULE_DEFAULTS` (built from `rulesToConfig(STANDARD_RULES)` plus every track key `false`) would disagree after a flip of one; chess hard-codes `defaults: { trackMoves: false, trackClock: false }` in index.tsx (H1). The "Standard / N custom" pill and Reset then disagree with a new match. | **Fixed:** cricket has one constant, `CRICKET_TRACK_DEFAULTS`, used by the fields and `LOCAL_RULE_DEFAULTS`; chess's card moved to the pure engine as `CHESS_LIVE_SETTINGS`, its defaults read from meta.ts (as carrom's DC4); snooker / pool cards read meta.ts too. Tested: every live field default = its format field default = `defaults[k]`. |
| DOK3 | **Reset turns options off.** "Reset to standard" (LiveSettingsCard `standardOf ?? f.default`) would reset to the OLD standard (off) if `defaults` was not flipped with the field. | **Fixed with DOK2:** Reset now gives the new defaults (cricket R7: a mid-match reset turns the captures on from the next ball, logged as SET_RULES "Pitch map on"; the card hint says so). Tested. |
| DOK4 | **Info shows ON while the engine has OFF.** `LiveScoringScreen` › Edit format seeds the form with `{ ...defaultsFor(fields), ...meta.config }`, and `matchCaptures` reads a format capture with `valueOf` (missing → field default). A match whose stored format has no key (made before the key existed, or by a path that stored a partial format) would show the switch On after the flip, while the engine (missing = off) scores it Off. Same for a live card whose `read` leaves a key out (`cur[k] ?? f.default`). | **Fixed (generic, every sport):** `existingFormatShown` (matchRules.ts) shows an existing match's stored format over today's defaults, but a "Stats to track" switch it never stored reads Off; the screen's Edit-format seed uses it, and `matchCaptures` reads a missing capture as Off (format captures and live-card toggles alike). Tested on cricket, snooker, pool and a synthetic sport. |
| DOK5 | **Snooker / pool: no way to switch it off mid-match (S2).** Neither had a `liveSettings` card, so a scorer who finds the long / rest chips (now on) in the way cannot turn them off; Info read the format only, so an Edit-format change after the start would say On while the engine froze the flag at init. | **Fixed:** `SNOOKER_LIVE_SETTINGS` / `POOL_LIVE_SETTINGS` (event mode, `SET_TRACK`, like carrom and chess): before the first shot a change patches the format; after it a logged `SET_TRACK` applies from the next shot (Undo names it "stats-to-track setting"). The scoring keeps going: SET_TRACK never changes a score, a turn, a frame or a rack. |
| DOK6 | **Switching off mid-match erases what was captured.** Snooker `snookerLongRestCaptured` and pool totals read the CURRENT switch (`trackLR`, `opt.shotClock`), so long pots / rest shots / extensions already tagged would vanish from the Stats tab and careers once the scorer switches the chips off. | **Fixed:** snooker counts the tags the match has (a tag can only exist when it was tracked at the time); pool writes `extensions` when the clock is tracked now or any extension was taken. Tested. |
| DOK7 | **The carrom fold hides a needed foul (C3).** Folding the fouls row behind "Fouls ▾" could hide it while a foul must be recorded: (a) once a foul was tapped in the match, every later board saves fouls (an untapped board is a real 0), so a folded row would write false zeros; (b) "Board ended on the loser's foul · Striker pocketed" also logs a striker foul; a folded row would hide that count. | **Fixed:** `carromFoulsOpen` (pure): the row is open once the scorer taps the link, once this board has a foul (the end-foul chip counts), or once the match has captured a foul (from then on every board is a real count). Folded only when nothing has been tapped in the match, where nothing is saved anyway. The link shows the board's count. Tested. |
| DOK8 | **False zeros.** Turning a capture on must not write "0" for what was never tagged: cricket pitch map / extra reason / bowler type / wagon wheel, snooker long / rest, carrom fouls. | **Holds:** cricket career keys are keyed (`coverage: 'keyed'`, only from tagged balls; the Stats tab says "N of M tagged"); snooker long / rest keys only once a tag exists (NZG1/NZG2); carrom fouls only from the first tapped foul (NZG3). Tested on untagged new-default matches; 600-user sim. |
| DOK9 | **Per-ball burden (~120 balls an innings).** With four cricket captures on, the describe card shows on almost every ball. If anything waits on it, a T20 costs ~240 extra taps. | **Holds:** the card sits below the pad and is replaced by the next ball (wave 2); the next ball is never blocked. Tested: 120 balls a side with the new defaults and no tag score exactly as with the captures off; sim: one-tap scoring never blocked in snooker (pot without a tag), carrom (record a board without break / fouls / covers), cricket. |
| DOK10 | **Shot control stays off** (cricket R1): on, an untagged ball counts as in control, so a skipped card gives Control 100% and a "Best control %" leader. Ball speed (typed, speed gun), pool shot clock, chess moves / clock stay off. | **Holds:** pinned off in the field, the live defaults and a new match's rules. |
| DOK11 | **Every stats toggle carries `group: 'Stats to track'`** (the tournament "Use the new defaults" button, Info captures and the card's chip row rely on it). | **Holds / fixed:** every cricket / snooker / pool / carrom / chess stats toggle, in the format and in the live card, carries the group. Tested. |
| DOK12 | **Old tournament formats.** A tournament created before the flip stored the keys `false`, so its new matches stay off. | **Holds (expected):** the organiser's saved choice; "Use the new defaults" offers the flip. Tested: a stored `false` stays off. |
