## Notes
- Free-hit policing needs `v: 2`, so old logs and old app versions behave as before. A newer app refuses the wicket even if its own UI ever offered it.
- Last man stands follows the common box / gully form: the lone batter keeps the strike. Local variants (for example, no runs to the keeper's end) are not modelled.
- The ODI bands follow the ICC proportion (20 % / 60 % / 20 %, nearest whole over) for a cut ODI. The exact ICC reduced-ODI table was not checked line by line.
- `ballEventMatches` moved from commentary.ts to the new timeline.ts (re-exported), so phases.ts can find where an innings was cut without an import cycle.
- Not checked on a device: the new chips (Substitute fielder, Bouncer, One short, last man bats on) and the strip are type-checked, not demo-driven.
