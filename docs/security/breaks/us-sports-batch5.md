# US sports batch 5: basketball team plays and pairings, baseball runner credits and fielders after the play, American football mode defaults: break it (2026-11-03)

From the expert audit `docs/sport-expert/us-sports.md`: basketball fix 3 (team rebound / team turnover, steal → turnover, block → missed shot), the team-rebound row and "U / D foul gives the ball", fixes 11, 12 (offensive part), 14; baseball fixes 6 and 13; American football fixes 10 and 17. Batches 1–3 already did fixes 1, 2, 4 and 5.

**Founder chain rule:** every capture option visible in Info → offered in Scoring → shown in Stats and Commentary.
**Hard rules:** old match logs replay identically; new payload keys and actions are additive; hostile values are ignored; one scorer on one phone, so every new tap is optional.

**Status: Fixed / Holds / Not done** (2026-11-03). Listed after reading the code and **before** any fix (quality mandate step 4). Each fix then got a failing test first (`tests/us-sports-batch5.test.mts`, 27 tests, written first: the file failed before the fix — the builders and keys did not exist) and the seeded simulation (`tests/sim-us-sports-batch5.test.mts`: 600 basketball games, 600 baseball games + 600 formats, 600 American football formats + 600 play-by-play games).

**Old logs replay identically — proof:** besides the tests and the simulation, a one-off oracle replayed 800 random old-format basketball logs and 800 baseball logs through the code at HEAD (before this batch) and through this batch: the same state JSON, statTotals, team figures, Stats panel and box score in every game (baseball totals equal apart from the six new derived keys); American football `init` equal for every preset × stored mode. The only difference on an old log is display text: a U / D / flagrant foul's commentary line now ends "· free throws and the ball" (BK7, accepted: it is the rule, and it was always so).
