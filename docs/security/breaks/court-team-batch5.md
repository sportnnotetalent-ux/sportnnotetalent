# Court and team sports, batch 5: break it (2026-11-03)

**Source:** expert audit `docs/sport-expert/court-team.md`. Batch 1 did fixes 1–3, batch 2 (info-chain) fixes 4–5, batch 3 fixes 6 (Set by), 7 and 8. This batch does what is left of the P1 list, plus two Stats gaps the founder named:

1. **Volleyball "Who was aced?"** (fix 6, deferred in batch 3 as DC3): its own light category `aced` (key `vbAced`), split out of Reception quality, on for new matches. A non-blocking row after an Ace.
2. **Volleyball warnings, expulsions, disqualifications and delays reach Stats** (fix 12): a Discipline category in the match centre.
3. **Volleyball fault chips** (fix 10): "Catch / lift" (`handling`) and "Back-row / libero fault" (`backrow`); "Foot fault" reads "Centre line" (the stored key `foot` is unchanged).
4. **Kabaddi technical-point reasons reach Stats:** Discipline › "Technical points conceded" splits by reason.
5. **Handball save with no keeper set** (fix 9): the team keeps its save and save %; an optional "Who's in goal?" row on the save screen names the keeper.

**Process:** quality mandate step 4. Listed after reading the code and **before** any fix, each with Status: Open. Each then got a failing test first (`tests/court-team-batch5.test.mts`: 12 of 17 failed before the fix; 5 held) and a seeded simulation (`tests/sim-court-team-batch5.test.mts`: 600 new-capture matches, 200 per sport, plus 180 old-style matches fingerprinted against the code before the batch).
