# Stats to track on by default, court-team family (wave 3): break it first

2026-11-08. Wave 3 of docs/sport-expert/defaults-on/PLAN.md for volleyball, kabaddi, netball and handball. The "Stats to track" options turn ON for NEW matches, following the specialist's ON list (docs/sport-expert/defaults-on/court-team.md). Wave 1 made "tracked = captured" (no-false-zeros-court-team.md). Wave 2 made the describe steps non-blocking cards (describe-court-team.md).

The target:

- **Volleyball:** `vbReception` and `vbDig` on. `vbAssist` and `vbAced` stay on. `vbAttack` stays off (an untapped "in play" makes attack efficiency look better, R2).
- **Kabaddi:** `trackSkills` on. `trackTouched` stays **off**: the quick "+1 touch" still has no non-blocking "Who was touched?" (K1 is not built in this wave), so the named-touch figures would only come from the raid form.
- **Netball:** `detail`, `trackCpr`, `trackGains`, `trackTurnovers` on in every preset (International, School, Halves, Custom).
- **Handball:** both switches already on. Kept.

Listed after reading the code and **before** any fix, each with Status: Open. Each then got a failing test first and the 600-user simulation (see Process below the table).
