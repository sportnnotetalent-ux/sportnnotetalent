# No false zeros in football, hockey, ice hockey and rugby — break it first

2026-11-08, wave 1 of `docs/sport-expert/defaults-on/PLAN.md` (specialist report `docs/sport-expert/defaults-on/invasion.md`, risk R1). In all five invasion sports a "Stats to track" option that is switched on counts as "tracked" even when the scorer never tapped it, so every player line, the team sheet and the careers read 0 for it ("Tackles 0 · Hits 0"). Wave 3 turns most of these options on by default, so this has to be fixed first. The rule is the one racket sports already use (`pointDetail.ts` `rallyTracked` / `netTracked` / `thirdTracked`, `describe-done.md` DD11): **a stat counts as tracked only once at least one event of that kind was captured in the match.** Switched on with nothing captured shows nothing and writes nothing to careers. The granularity is the *kind* (a tackle, a hit, a carry), not the whole toggle, so a scorer who only taps tackles gets no "Carries 0". Two kinds that only make sense together count as one family: a tackle and a missed tackle (tackle success). The switch itself still means "offered": the buttons, chips and voice commands follow the toggle exactly as before. Goals, assists, cards and the other core records every scorer takes are out of scope (they are not "Stats to track" options; a red card is always offered).
