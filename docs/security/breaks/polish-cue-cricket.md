# Wave 4 polish: snooker and carrom detail in the commentary, honest bouncer wording (2026-11-08)

Follows wave 3 (`defaults-on-cricket-cue.md`): snooker "Long pots and rest shots", carrom break / fouls / missed Queen covers and the cricket pitch map are now ON by default. Specialist items: `docs/sport-expert/defaults-on/cue-board.md` D1 / D2 ("Describe cards" 1 and 4) and `docs/sport-expert/defaults-on/cricket.md` R5. Fixed rule (wave 1, `no-false-zeros-cue-golf.md`): **tracked means captured** — a line mentions a detail only when the scorer captured it.

**Status: Fixed** (2026-11-08). Listed after reading the code and **before** any change (quality mandate step 4). Each fix got a failing test first (`tests/polish-cue-cricket.test.mts`), then a 600-match simulation in the same file.

## Where the scorer sees "the last play"

- **Snooker:** the commentary (`snooker/feed.ts`) has one line per visit; the engine keeps a visit's tags as counts only (`lp` long pots made, `lm` long pots missed, `rs` strokes with the rest, `engine.ts` `strokeFlags`). The line right under the pad that names the last shot is the Undo bar (`snooker/undo.ts`: "red · break 8").
- **Carrom:** the commentary (`carrom/feed.ts`) already has a detail line (`sub`) per board. The line that names the board just recorded is the Undo bar (`carrom/undoLabel.ts`: "board to Rahul +4 with the Queen (17-9)").
- **Cricket:** the bouncer slot above the run pad and the detail card note (`cricket/bouncers.ts`), and the organiser's hint for "Bouncers allowed per over" (`cricket/rules.ts`).

## What changed and why (R5)

The bouncer count was never wrong, but its words were: it said "bouncers this over" when it only knows the bouncers the scorer **tagged**. With the pitch map on by default, many school scorers will skip the length chips, and a quiet slot would read as "no bouncers yet". Adding "tagged" to the three warning strings and rewording the organiser hint makes each line claim only what was captured. The count, the limit, the slot's position and when it shows are unchanged.
