# Racket sports: forced-error types, lost by rule, doubles winner credit: break it (2026-11-03)

Badminton, table tennis, squash, padel, pickleball. Fixes F4, F5 and F1 of `docs/sport-expert/racket.md` (and the shared section, items 1 and 2), copying the tennis pass (`tennis-endings-depth.md`). Founder decision 2026-11-03 for F1: **new matches only**, old matches keep their credits.

**Process:** quality mandate step 4. Listed after reading the code and **before** any fix. Each fix then gets its own failing test first (step 5).

**Status: Fixed** (every point Fixed or Holds; RD11 accepted). Tests: `tests/racket-depth.test.mts` (21). Simulation: `tests/sim-racket-depth.test.mts`, 250 matches across the five sports, singles and doubles, rally and side-out scoring (several thousand rallies, asserted ≥ 1,000; about 750 players, asserted ≥ 500; with hostile details).

## What a stat-keeper records (BWF, ITTF, WSF / PSA, FIP, USA Pickleball)
- **Forced errors by type**, as the sport already types unforced errors: badminton net / out / fault, table tennis net / out, squash tin / out, padel net / out, pickleball net / out / kitchen / foot.
- **Lost by rule**: neither a winner nor an error. Badminton (Law 13): net touch, double hit, obstruction, receiver fault. Table tennis (2.10): obstruction, free hand on the table, moved the table, double hit. Squash: double hit, carry. Padel: net touch, ball hit before it crossed, double hit. Pickleball: two-bounce rule, non-volley-zone momentum, net touch.
- **Who hit the winner in doubles**: the hitter, not the server.
