# Undo labels in every sport, and the Quick options sheet closing: break it (2026-11-03)

Two follow-ups from the on-screen QA sweep:

- **(A)** the Undo bar says a plain "Undo" / "Undo last update" in hockey, handball, kabaddi, chess and carrom instead of naming what it removes (other sports: "Undo: point to Nadal (30-15)", "Undo: shuttle change").
- **(B)** after an action applied from the ☰ Quick options sheet (a padel time violation, a badminton shuttle change), the sheet stays open.

**Process:** quality mandate step 4. Listed after reading the code and **before** any fix. Each fix got a failing test first (step 5), in `tests/undo-labels-quick-sheet.test.mts`; simulation in `tests/sim-undo-labels.test.mts`.

**Status: Fixed** (every point Fixed or Holds). Tests: `tests/undo-labels-quick-sheet.test.mts` (16). Simulation: `tests/sim-undo-labels.test.mts`, 600+ random steps per sport (3,000+ in all, hostile payloads mixed in). No reducer, scoring or stored field changed.
