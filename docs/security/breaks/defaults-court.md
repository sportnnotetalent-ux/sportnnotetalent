# Court sports, batch 3: richer stats on by default for new matches: break it (2026-11-03)

**Source:** founder rule (2026-11-02): "only what is captured in scoring is seen in stats". The chain Info settings → Scoring → Stats + Commentary must hold in every sport. Tennis turned point detail on for NEW matches only (`tennis-serve-and-endings.md` TF2 / TF6). This batch does the same for four court sports, from the expert audits `docs/sport-expert/us-sports.md` (basketball, fix 5) and `docs/sport-expert/court-team.md` (volleyball fix 6, netball fix 7, handball fix 8).

1. **Basketball:** "Track missed shots" on for new matches (FG%, 3P%, EFF, the shot chart's misses).
2. **Volleyball:** "Set by?" (set assists) on for new matches. "Who was aced?" only if small and non-blocking.
3. **Netball:** "Feeds & rebounds" on for new International 4 × 15 matches; the centre-pass-receive default must agree between the format fields and the live settings card.
4. **Handball:** technical fault types on (the chip costs no extra tap); "7 m won by" as a chip row on the 7 m result screen (no extra step), then on.

**Process:** quality mandate step 4. Listed after reading the code and **before** any fix, each with Status: Open. Each then got a failing test first (`tests/defaults-court.test.mts`: 14 of 21 failed before the fix) and a seeded simulation (`tests/sim-defaults-court.test.mts`: 1,040 matches, 130 old + 130 new per sport). Two older tests pinned the old defaults and were updated: `court-team-round2.test.mts` (BB_TRACK_DEFAULTS) and `netball-deep.test.mts` (stats switches off except CPR).
