# Tennis: rulebook audit (2026-11-05)

Sixth sport. Tennis has had the deepest earlier passes (`docs/security/breaks/tennis-serve-and-endings.md`, `tennis-endings-depth.md`, `racket.md`), so this pass checks for 2026 changes.

## Result

No 2026 change touches scoring. The tour summary lists none for match format, code violations, time rules or line calling. The only change to the Rules of Tennis is Rule 3 (the ball, equipment).

## Checked and fine

- Formats: best of 3 / 5, a match tie-break to 10 in place of the 3rd set, no-ad, short sets to 4, Fast4, pro set to 8. ✓
- Grand Slam deciding set: games, then a 10-point tie-break at 6-6 (since 2022). ✓
- Tie-break to 7, ends change every 6 points; the next set is served by the player who received first in the tie-break. ✓
- ITF Point Penalty Schedule (warning → point → game) and time violations, per side; medical / toilet breaks. ✓

No findings.
